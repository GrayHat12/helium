### Conclusions

* **Substantial Speed Advantages:** Helium finishes executing the loop and printing operation significantly faster than Python. Looking at the overall wall-clock time, Helium delivers a $\approx 2.64\times$ speedup. The difference is even more profound in user space execution code, where Helium runs $15.00\times$ faster than Python ($0.01\text{ s}$ vs. $0.15\text{ s}$).
* **Extreme Memory Efficiency:** Helium has an incredibly lightweight footprint compared to Python. It consumes a maximum of only $392\text{ KB}$ of memory, while Python needs $10324\text{ KB}$. This indicates that Python utilizes $\approx 26.34\times$ the amount of memory Helium requires to perform the identical structural logic. 
* **Minimal Operating System Overhead:** The high number of minor page faults ($18990$) and voluntary context switches ($294$) generated by Python indicates significant system-level friction. This behavior is typical of interpreted languages that undergo extensive environment setup, runtime virtual machine allocations, and complex string formatting routines. Conversely, Helium's tiny footprint of $161$ page faults and $2$ voluntary context switches implies it compiles down to direct, highly optimized machine code or uses an exceptionally streamlined runtime environment.
